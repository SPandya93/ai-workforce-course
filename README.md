# AI Essentials for the Workforce

A static course companion for CLL 484-61, Fall 2026, taught by Dr. Shyamal S. Pandya at Jackson State University.

## Publish with GitHub Pages

1. Create a repository named `ai-workforce-course` under your GitHub account.
2. Upload this directory's contents to the repository root on the `main` branch. Keep `index.html`, `style.css`, `app.js`, `.nojekyll`, and the `assets` directory together.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose **main** and **/ (root)** and save.
5. Wait for GitHub's Pages deployment to complete and use the published URL shown in Settings → Pages.

No package installation, API key, server, or build step is required.

## Content and updates

- `index.html`: course overview, applied activities, innovation pathways, grading, policies, and contact details.
- `app.js`: semester schedule, filters, project tabs, image dialogs, and the local prompt builder.
- `style.css`: responsive course design and local font definitions.
- `assets/course-syllabus.pdf`: the supplied Fall 2026 syllabus.
- `assets/`: illustrative artwork and locally hosted fonts.

The site uses relative asset paths, so it works under a GitHub Pages project subdirectory. Canvas remains the source for updated meeting arrangements, final assignment instructions, submissions, and grades. The prompt builder assembles text locally without calling an AI model or saving entries.
